## ⚡ 4. Non-Negotiable Performance Invariants

1. **Cumulative Layout Shift (CLS = 0.00):** Every asynchronously loaded drawer, map, terminal, or chat module must mount alongside its respective `SectionSkeleton`.
2. **Kinematic Refresh Rates:** Animation and cursor loops must run locked at **60 to 120 FPS**.
   - Zero `getBoundingClientRect()` calls inside `requestAnimationFrame`.
   - Pre-allocated fixed particle pools (`MAX_PARTICLES = 60-70`).
3. **Z-Index Layer Hierarchy:**
   - `z-0` – `z-30`: Base sections and background canvas layers
   - `z-40`: Section headers
   - `z-50`: Top Navbar and active role indicator
   - `z-[60]`: Centralized Floating Action Hub (container `pointer-events-none`)
   - `z-[70]`: Back to Top Floating Controller
   - `z-[80]`: Slide-out Drawers (Lab Studio, Case Studies) and Terminal CLI Modal
   - `z-[85]`: Docked AI Chat Station
   - `z-[90]`: Credential Lightbox Modal & Spotlight Command Palette
   - `z-[100]`: System Toast Alerts & Critical Safety Overlays
